# 任务：打磨 1962 日课旧约颂歌的中文（忠于拉丁通行本）

## 背景

1962 罗马日课晨祷（Laudes）等时辰里有一批旧约颂歌（三童歌、依撒意亚、德训篇、编年纪、友弟德传、耶肋米亚、多俾亚传、希则克雅之歌、哈巴谷、亚纳、梅瑟之歌）。拉丁文是**拉丁通行本（Clementina）**。站内中文以**思高圣经**为底本，与拉丁通行本不同处改从拉丁文，改动处用 `**…**` 标粗，并在注释里写明思高原文。中文只作阅读参考，不用于诵念，但必须忠于拉丁文、语言庄重自然。

## 你要编辑的文件

`resources/officium1962-ot-canticles/lines.json`：数组，每项：

- `id`、`ref`、`prefix`、`canticle`、`latin`：**只读，不要改**。`latin` 是这一行的拉丁文（`*` 是半句分隔）。
- `zh`：中文。**可改**。
- `notes`：注释数组（可无）。**可改**。

## 参考资料（只读）

1. `resources/officium1962-ot-canticles/sigao-epub-ot.json`：《思高本.epub》简体，结构 `{书: {章: {节: 文}}}`；书键 Exod、Deut、1Sam、1Chr、Tob、Jdt、Sir、Isa、Jer、Dan、Hab。**注意**：拉丁通行本的节号与思高常不一致（友弟德传、多俾亚传、德训篇、依撒意亚 38/45、耶肋米亚 31、撒上 2、出 15 等），要按内容对应，不要按节号硬套。
2. `resources/officium1962-ot-canticles/lh-reference-wanyou.json`：时辰礼仪（《日课》万有真原版）中文，其中有若干颂歌的译文（Ex 15、Dt 32、Sir 36、Is 38、Is 45、1 Chr 29、Dan 3）。它依据新拉丁文本，**仅作措辞参考**，措辞通顺处可借用，但内容要以本行的 `latin` 为准。
3. 已有的写法示例：`scripts/officium1962/canticles-zh.mjs`（Te Deum、赞主曲等已完成，注释格式照此）。

## 规则

1. **忠于 `latin`**：中文意思必须与这一行拉丁文一致。拉丁文有而中文漏掉的要补，中文多出的要删。拉丁文本身难解之处，选最稳妥的理解，不要发挥。
2. **思高为底**：未标粗的字应是思高 epub 原文（可调整标点、半句位置 ` * `、语序以对应拉丁行）。若发现现有未标粗的字与 epub 不符（旧底本有错字、生硬处），改回 epub 原文。
3. **标粗＝与思高不同**：凡思高原文不能表达拉丁文而改写之处，必须用 `**…**` 标粗，并在 `notes` 里写一条注释，格式：`思高本作「……」，拉丁通行本作「……」（译文），故此处改从通行本。` 注释里的「思高本作」必须逐字取自 epub。标粗处和注释一一对应（一行可有多条注释，按先后排）。不再用「武加大」「Vulgate」字样，统一称「拉丁通行本」。
4. **语言打磨**（主要对象是标粗的改译部分和注释）：
   - 去掉欧化腔与和合本腔（如「以……为卑」「当……的时候」「所……的」堆叠），不用口语；
   - 贴近思高圣经与天主教礼仪的文风：庄重、简练、四字或对仗自然；
   - 人名地名用思高译名（如雅各伯、依撒格、培肋舍特、米德扬、耶路撒冷）；
   - 称呼与代词：「上主」「天主」；对天主的第二人称用「你」，不用「祢」。
5. 半句分隔 ` * ` 的个数尽量与 `latin` 一致；中文语序无法对应时可不拆（不含 ` * `）。
6. 不要新增或删除条目，不要改 `id/ref/prefix/canticle/latin`。保持 JSON 合法、UTF-8、缩进不变。

## 校验

编辑完你负责的每个 `id` 范围后运行：

```
node scripts/officium1962/ot-canticles-check.mjs --ids=A-B
```

必须 0 个问题。最后用中文简短汇总：改了多少行，哪些行拉丁文难解、需要人工复核。
