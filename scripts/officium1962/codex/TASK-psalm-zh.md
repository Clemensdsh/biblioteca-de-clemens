# 任务：1962 罗马大日课圣咏中文（思高）逐篇切分与校订

你负责若干篇圣咏（由调用者的提示给出篇号 PSALMS）。目标：为每个 **Divinum Officium（DO）分行** 配上中文，中文取自**思高圣经**（《思高本.epub》整理出的 `resources/officium1962-psalms-zh/sigao-epub.json`），拉丁文是 DO 的 Clementina 武加大。页面左拉右中对照，所以**每一行拉丁文必须有语义对得上的中文**。

## 铁律
1. **以思高为准**：中文用词、标点原样取自思高文本；只在“武加大与思高真正不同”处才改，改动处用 `**…**` 标粗，并在 `note` 里说明（拉丁原文怎么说、思高怎么说、为何这样改）。
2. 不得硬配：拉丁与思高语义对不上时，宁可按武加大另译该行（整行或该半行粗体，note 说明），也不要让中文和拉丁说的不是一回事。另译时尽量沿用思高的词汇和文风；不要调用在线翻译。
3. 两半句的次序若与武加大相反，可对调（verbatim 句子，不增删），note 注明“仅对调”；不要为了顺而改思高字句。
4. 不修改拉丁文、不修改 `vendor/`、`resources/officium1962-latin/`、`public/`、`features/`、`components/` 等任何其他文件。只写你负责的篇：`resources/officium1962-psalms-zh/psalms/NNN.json`（NNN 三位篇号）。**不要运行不带 `--check` 的 build**（会并发写同一输出文件）。
5. 旧的草稿在 `resources/officium1962-psalms-zh/psalms-v1-txt/NNN.json`（对旧底本写的，那个底本有错字和漏句，措辞与现底本不同，**仅供参考切分思路和我当时判断出的差异点，不可照抄**，必须对着现底本和拉丁重新核对）。

## 材料
- DO 拉丁分行：`vendor/divinum-officium/web/www/horas/Latin/Psalterium/Psalmorum/PsalmN.txt`（行标号如 `5:7b`；同标号出现两次的，第二行起记为 `5:4#2`；行内 `(8a)` 之类是跨节标记；`* † ‡` 是半行/断句符）。
- 参考的希伯来式拉丁（庇护十二世圣咏本，译自希伯来文）：`vendor/divinum-officium/web/www/horas/Latin-Bea/Psalterium/Psalmorum/PsalmN.txt`。Clementina 与它差别大的地方，往往就是与思高不同的地方，可用来定位差异。
- 思高文本：运行 `node scripts/officium1962/psalms-zh-build.mjs --check --worksheet=N --all` 会打印该篇每一行 DO 拉丁、当前自动配出的中文，以及末尾的“思高原文”（`vN:` 是节号，标题常并在第 1 节；第 115、147 篇的节号分别是 10–19、12–20；`vN` 里没有空格分行）。
- 武加大圣咏的判读请用你自己对拉丁文的知识；思高译自希伯来文，因此遇到以下情形要特别小心：七十士/武加大的增补句（如第 13 篇罗马书引文段）、动词人称/时态/语气不同、词义不同（如“irascimini”与“战栗”）、半句顺序颠倒、一节被拆合、希伯来标题与节号错位。

## 文件格式 `psalms/NNN.json`
```json
{
  "reviewed": true,
  "lines": {
    "5:3": { "from": "我的君王", "to": "上主，我在向你哀恳", "mk": ["我的天主，"] },
    "5:7b": { "zh": "…**粗体**… * …", "note": "说明" }
  }
}
```
- 键＝`篇:DO行标号`（含 `#2`）。**没有写入的行，仅当它是“一行对应思高整一节、且节号对得上”时才会自动取思高该节全文**；其余行必须写规格，否则 build 会报“已校订篇内缺中文”。
- 规格字段：
  - `from`：中文起点——思高整篇文字流里**首次出现**（在上一行起点之后）的那段字（需完全匹配思高字、标点）。
  - `to`：中文终点——取到这段字之前（不含）。省略时到下一行的起点。**凡本行与下一行之间夹有自己写了 `zh` 的行、或下一行的起点不在本节开头，必须写 `to` 或给下一行写 `from`。**
  - `mk`：字符串数组。依次在这些字符串之后插入拉丁行里的 `* † ‡`（个数必须等于拉丁行里这类符号的个数）。思高没有分行空格，**半行符号靠 `mk` 放到最合适处**（对着拉丁的半句位置放）。
  - `marks`：旧写法（按空格分小句），思高现底本无空格，一般不用。
  - `fix`：`[[旧字, 新字],…]`，对切出的中文做替换；新字里含 `**` 则原样使用（可只粗体改动的几个字），否则整段粗体；新字为空表示删去。
  - `zh`：整行手写中文（可含 `**…**`、可自带 ` * `/` † `；自带则不再自动放符号）。仍可用 `from` 给上一行划终点。
  - `note`：注释（中文，简明）。同一篇相同 note 会合并。
- 每篇做完设 `"reviewed": true`；做不完的篇不要标 reviewed（不写文件或写 `"reviewed": false`），并在最终回复里说明卡在哪里。

## 操作流程（每篇）
1. `node scripts/officium1962/psalms-zh-build.mjs --check --worksheet=N --all`，通读该篇所有 DO 行与思高文字流。
2. 逐行决定中文：确定它对应思高文字流中的哪一段（半行/一节的一部分/跨节），写 `from`/`to`；半行符号用 `mk`；有真实差异再加 `fix` 或 `zh`＋`note`。
3. 写 `psalms/NNN.json`，再跑一遍上面的命令，**逐行检查**：中文是否与该行拉丁语义一致、有无多出/缺少、分行位置与拉丁半句位置是否合理、无 `错误：` 输出、无“已校订篇内缺中文”。有问题就改，直到干净。
4. 全部篇完成后，运行 `node scripts/officium1962/psalms-zh-build.mjs --check`，确认其中你负责的篇没有错误。

## 质量要求（用户最在意）
- 每一行的中文和拉丁语义必须对应；不要留着大段来自相邻行的多余中文，也不要漏掉拉丁行里有的内容（思高没有的内容要按武加大补出并粗体）。
- 判断“真正不同”要对照拉丁意思逐节想一遍，不是只看词面相似度。常见漏点：祈愿/陈述、第一二三人称、单复数、时态、专名、被动/主动、否定、整句有无。
- 注释要写清楚：武加大怎么说（可引拉丁短语）、思高怎么说、本行怎么处理。

## 最终回复（中文）
列出：完成的篇号；未完成及原因；你不确定的地方（篇:行 + 简述）；发现的底本问题（epub 文字疑似错漏）。
