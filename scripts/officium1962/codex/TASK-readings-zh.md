# 任务：1962 日课圣经读经中文（思高为底，忠于拉丁通行本）

## 背景

1962 罗马日课里直接取自圣经的读经（短读经 Lectio brevis、小读经 Capitulum、夜课 Matutinum 的圣经读经）拉丁文是**拉丁通行本（Clementina）**。站内中文以**思高圣经**为底本；思高与拉丁通行本不同处，**改从拉丁文**，改动处用 `**…**` 标粗，并写注释。做法与站内圣咏、旧约颂歌完全一样（可看 `scripts/officium1962/codex/TASK-polish-ot-canticles.md`、`resources/officium1962-ot-canticles/lines.json` 的写法）。中文只作阅读参考，但必须忠于拉丁文、语言庄重自然。**不要照抄时辰礼仪译文**，也不要用和合本或其他译本。

## 你要编辑的文件

你的工作文件是**分配给你的组文件** `resources/officium1962-readings/groups/g-XXXX-YYYY.json`（只含你负责的条目）。**不要打开或修改 lines.json 与其他组文件**；也不要整文件重写成别的内容——只在你的组文件里逐条填写 `zh` 与 `notes`，保持每条的只读字段和条目数不变。组文件是数组，每项一行拉丁文：

- `n`、`id`、`ref`、`book`、`num`、`latin`、`sigaoRefs`、`sigao`、`uses`：**只读，不要改**。
  - `ref`：该行所属读经的引文（拉丁通行本缩写，如 `Sir 1:11-15`）；`num`：夜课读经按节分行时的节号（Vulgate 节号，无则是整段读经）；`latin`：这一行的拉丁文。
  - `sigao`：脚本按引文和节号自动取的思高本对应节，仅作**草稿线索**，**可能错位或为空**（通行本与思高的章节编号常不同，尤其德训篇、达尼尔、艾斯德尔、玛加伯、依撒意亚、耶肋米亚、哀歌、约伯传等；`num` 对不上时 `sigao` 会空或错）。
- `zh`：中文。**要写**。
- `notes`：注释数组（可无）。**要写（有标粗时）**。

## 查思高本

思高本全文在 `resources/officium1962-readings/sigao-bible.json`（结构 `{order, bible:{书名:{章:{节:文}}}}`，简体）。查经文用脚本：

```
node scripts/officium1962/readings-sigao.mjs "Sir 1:11-15" --pad=2
```

引文书名用拉丁通行本缩写，脚本自动转思高书名。**对不上节号时多看前后节（`--pad`），按内容找对应的思高经文**。书名对照：1–4 Reg＝撒慕尔纪上下、列王纪上下；1–2 Par＝编年纪上下；1–2 Esdr＝厄斯德拉上下（即厄斯德拉/乃赫米雅）；Sir＝德训篇；Sap＝智慧篇；Eccl＝训道篇；Cant＝雅歌；Joannes＝若望福音；Apo/Apoc＝默示录；Act/Acts＝宗徒大事录；Jac/Jas＝雅各伯书。

## 规则

1. **忠于 `latin`**：中文意思必须与这一行拉丁文一致。拉丁文有而思高没有的要补，思高有而拉丁文没有的要删。一行只写这一行拉丁文的意思，不要把邻行的内容并进来；也不要写节号（节号页面另显示）。拉丁文本身难解之处，选最稳妥的理解，不要发挥。
1a. **摘录**：礼仪读经常只取某节的前半或一部分，拉丁行到哪里止，中文就译到哪里止；思高多出的后半句直接略去，不必注释。
2. **思高为底**：未标粗的字必须是思高本原文（可调整标点、语序、人称以对应拉丁行）。思高与拉丁文**意思相同**的地方，哪怕措辞不同，也保持思高原文不标粗；只有**意思不同或有无不同**才改写。
3. **标粗＝与思高不同**：凡思高原文不能表达拉丁文而改写、补充之处，用 `**…**` 标粗，并在 `notes` 里写一条注释，格式：`思高本作「……」，拉丁通行本作「……」（译文），故此处改从通行本。` 若是思高有而拉丁文无，可写：`思高本有「……」，拉丁通行本无此句，故此处删去。`（删去处不必标粗，但仍要写注释，把注释附在紧邻的标粗处；若无标粗可附，则在删去处前后合理位置用 `**…**` 标出相邻保留的一小段，使注释有所依。）**「思高本作」引文必须逐字取自思高本该书**（脚本会核对）。标粗处与注释一一对应，按先后排；一行可有多条。统一称「拉丁通行本」，不用「武加大」「Vulgate」。
4. **语言**：贴近思高圣经与天主教礼仪文风，庄重简练；人名地名用思高译名（雅各伯、依撒格、培肋舍特、耶路撒冷……）；称天主「上主」「天主」，对天主第二人称用「你」，不用「祢」；去掉欧化腔和口语。
5. 拉丁行里的 `*` 半句分隔若有，中文用 ` * ` 对应（个数不多于拉丁）；无则不加。
6. 拉丁文里夹着的 `(…)` 说明性插入语照译。
7. 不要新增或删除条目，不要改只读字段。保持 JSON 合法、UTF-8、缩进不变。

## 校验

改完你负责的范围后运行：

```
node scripts/officium1962/readings-check.mjs --file=<你的组文件路径>
node scripts/officium1962/readings-check.mjs --file=<你的组文件路径> --warn
```

第一条必须是「0 个问题」。第二条列出的「非粗体小句不在思高本中」警告请逐条看：多半是你无意改了思高原文（应改回，或标粗并加注释）；若是确有理由的措辞调整（语序、人称、标点），可保留。

最后用中文简短汇总：完成多少条、改写了多少处、你认为拉丁文难解需人工复核的行（写 `n` 与原因）。
