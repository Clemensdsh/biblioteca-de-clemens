# 任务：从《每日颂祷》扫描本提取圣人简介（十一月，试做）

PDF：`Q:\下载\每日颂祷扫描测试\每日颂祷（1-3合集）.pdf`（只读，不要修改）。这是香港教区《每日颂祷》三册合订的扫描本，竖排繁体。PDF 的文字层是乱码，不能用，必须看图识读。

第三册“圣人专用”部分在 PDF 第 5121–5537 页。PDF 页码与书页码一一对应（例如 PDF 第 5480 页 = 书第 1248 页，十一月一日诸圣节附近；PDF 第 5520 页 = 书第 1288 页，十一月二十一日圣母奉献日）。本次只做**十一月**：大约 PDF 第 5465–5537 页。先确认十一月第一个节日从哪一页开始。

## 要提取什么

每个节日（或纪念）的条目开头是：日期（如“十一月二十一日”）、节日名称（大字，如“聖母奉獻日”），名称之下常有一段**小字**的圣人或节日简介（如“在公元五四三年的今天……”）。之后才是“經文見……”“誦讀”等正文。

只提取这段小字简介。没有简介的条目也记一行，`bio` 留空。

## 怎样做

1. 用 Python 的 PyMuPDF（`import fitz`，已安装）把页面渲染成图片，存到本文件夹下的 `ocr-work/`（例如 dpi=200；简介那一块可以用 `clip` 再放大渲染）。用你的看图工具阅读图片。
2. 竖排从右到左、每列从上到下读。照原样转录：繁体、原书标点、原书用字，不改错字、不改简体、不补字。看不清的字写成 `〔?〕`，猜得出的写成 `〔猜测字?〕`。跨页的简介要接上下一页。
3. 每段转录完，放大重看一遍原图，逐字核对一次再写入。
4. 结果逐条追加写入 `ocr-out/november.jsonl`（UTF-8，每行一个 JSON 对象）：

```json
{"date": "11-21", "title": "聖母奉獻日", "bio": "在公元五四三年的今天，……", "pdf_pages": [5520], "book_pages": [1288], "uncertain": 0, "note": ""}
```

- `date`：月-日，两位数。
- `title`：原书印的名称（照抄）。
- `bio`：简介全文（不含名称、不含“經文見……”）。
- `uncertain`：`〔?〕` 和 `〔…?〕` 的个数。
- `note`：任何需要说明的情况（如跨页、版面特殊）。

## 进度

做完一个条目就写一行，不要攒到最后。如果中途停下，下次从 `ocr-out/november.jsonl` 里最后一个日期之后接着做。整个十一月做完后，用中文简短报告：共多少条目、多少条有简介、不确定的字共有几处。
