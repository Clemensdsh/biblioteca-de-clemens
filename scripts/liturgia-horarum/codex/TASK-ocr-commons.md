# 任务：从《每日颂祷》扫描本逐页转录「聖人通用部份」（PDF 第 1202–1481 页，参数 FIRST、LAST）

PDF：`Q:\下载\每日颂祷扫描测试\每日颂祷（1-3合集）.pdf`（只读，不要修改）。香港教区《每日颂祷》三册合订的影印本，**竖排繁体**，PDF 的文字层是乱码，不能用，必须看图识读。

本批只做运行时指定的 `FIRST`–`LAST`（含两端）PDF 页。整个范围 1202–1481 是第一册的“通用經文部份”（教堂奉獻日、聖母慶節、使徒、殉道者、牧者、教會聖師、貞女、聖人、教育家等通用）；1202 页是部份标题页，1203 页是目录，1481 页是“聖人專用部份”的标题页（本批若遇到，照样记一行，`text` 写标题即可）。页内容多为：圣咏、对经（對經）、读经（短讀經）、答唱、福音歌对经、禱文、禱詞（Preces，“求主垂聽”类祈求）、**同一节日通用的各时辰**。

## 目的

后续要把这些中文与拉丁《Liturgia Horarum》的通用部分逐句配对，所以**宁可保守也不要猜**：原样转录，不改错字、不改繁体、不改标点、不补字、不规整。

## 怎样做

1. 用 Python 的 PyMuPDF（`import fitz`，已安装）把页面渲染成图片，存到 `ocr-work/commons/`（建议 dpi=200；每页可再把页面分成左右两半各放大渲染一次，更容易看清）。用你的看图工具阅读图片。不要用文字层。
2. 竖排：**每一栏自右向左、每栏自上而下**读。页面常分成上下两大块，或有框线隔开的几块，先看清版面再读。标题（大字、粗体、居中）、页眉（页码与书眉）、小字说明、符号都要转录。
3. 输出成**横排文本**，规则：
   - 原书的**每一竖栏转成一行**（不要把几栏合成一段）；栏内原有的自然换行也保持为一行。
   - 同一块（如一首圣咏、一组对经、一段读经）内的行连续写；不同的块之间空一行。块的顺序按阅读顺序（先右后左；上下两块则先上后下）。
   - 保留所有符号：`※`（半句分隔）、`＋`（画十字）、`☆`、`◎`、小圆点、括号、阿肋路亞的括注、“領：”“答：”“對經一：”等标签、经文出处（如“（羅一二，12）”）、栏首缩进体现的层次不用管。
   - 小字（如“聖詠一四六”下的说明、方括号提示）也照抄。
   - 页眉：写在 `header` 字段，不放进 `text`。页眉里的页码是**书页码**，写在 `book_page`。
   - 看不清写 `〔?〕`；猜得出的写 `〔猜測字?〕`。一个字也不要编造。
4. 每页转录完，把图放大重看，逐栏核对一次，再写入。核对时特别留意：形近字（己已巳、未末、日曰、土士）、“祢”（指天主）与“你”、“祂”与“他”、标点位置、栏的遗漏或顺序颠倒、栏尾的“※”。
5. 结果**逐页追加**写入 `ocr-out/commons/b<FIRST>-<LAST>.jsonl`（UTF-8，每行一个 JSON 对象，一页一行；已有内容则从最后一页之后接着做）。格式：

```json
{"pdf_page": 1204, "book_page": 607, "header": "教堂奉獻日通用", "kind": "text", "text": "第一晚禱\n\n聖詠一四六\n...", "uncertain": 0, "note": ""}
```

- `pdf_page`：PDF 页码（整数）。`book_page`：页眉里的书页码，没有则 `null`。
- `header`：页眉文字（书眉），原样。
- `kind`：`"title"`（部份标题页）、`"index"`（目录）、`"blank"`（空白页）、`"text"`（正文）。
- `text`：按上面的规则转成的横排全文；栏与栏、行与行之间用 `\n`，块之间用空行（`\n\n`）。
- `uncertain`：`〔?〕` 与 `〔…?〕` 的个数。
- `note`：需要说明的版面情况（跨页的块、页内插图、极小字等），没有则为空串。

## 其他要求

- 做完一页就写一行，不要攒到最后；中途停下，下次从该文件的最后一页之后接着做。
- 不要修改 `ocr-out/commons/` 里其他批次的文件，不要改仓库的其他文件；工作图片放 `ocr-work/commons/`（不入库）。
- 结束时用中文简短报告：起止页、总页数、各类 `kind` 页数、不确定字总数、版面特殊情况、尚未做完的页（若有）。
