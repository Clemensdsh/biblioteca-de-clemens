# 任务：从《每日颂祷》扫描本提取圣人简介（按月，参数 MONTH）

与 `TASK-ocr.md`（十一月试做）方法完全相同，本文件只说明如何套用到其他月份。先完整读 `TASK-ocr.md`，其中的方法、转录规则、JSON 格式、逐字核对要求全部适用；只把“十一月”换成运行时指定的月份。

PDF：`Q:\下载\每日颂祷扫描测试\每日颂祷（1-3合集）.pdf`（只读，不要修改）。竖排繁体扫描本，文字层是乱码，必须看图识读。第三册“圣人专用”部分在 PDF 第 5121–5537 页；PDF 页码与书页码一一对应（5480 = 书第 1248 页，十一月一日附近）。已知十一月在第 5465–5537 页附近，据此二分查找目标月份的起止页（先看各页日期标题，不要从头逐页读）。如果该月在这个范围内找不到，在 `note` 说明，并在整册范围内查找日期标题；仍找不到就在最终报告中如实说明，不要编造。

## 要求

- 只做指定月份；输出写入 `ocr-out/<month>.jsonl`（如 `ocr-out/01.jsonl`，两位数月份），每个节日/纪念一行，格式与 `november.jsonl` 相同，逐条追加，已有内容则从最后一个日期之后接着做。
- 工作图片放 `ocr-work/<month>/`，不要覆盖其他月份的文件。
- 只提取名称之下小字的圣人/节日简介；没有简介的条目也记一行，`bio` 留空。照原样转录：繁体、原书标点、原书用字；看不清写 `〔?〕`，猜测写 `〔猜测字?〕`；每段放大重看并逐字核对。
- 不要修改 `ocr-out/` 里其他文件、不要改仓库其他文件。
- 结束时用中文简短报告：该月起止 PDF 页、条目数、有简介条数、不确定字处数、版面特殊情况。
