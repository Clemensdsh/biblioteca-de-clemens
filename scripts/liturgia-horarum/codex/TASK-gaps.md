# 任务：在《每日颂祷》扫描本中定位并逐页转录若干缺口条目（参数 IDS：逗号分隔的 target id）

PDF：`Q:\下载\每日颂祷扫描测试\每日颂祷（1-3合集）.pdf`（5547 页，只读，不要修改）。香港教区《每日颂祷》（1971 年版译本）三册合订影印本，**竖排繁体**，文字层是乱码，必须看图识读。

目标清单在同目录 `gap-targets.json`（`anchors` 给出页码锚点，`targets` 里每个对象有 `id`、`find`、`hint`）。本批只做参数 `IDS` 指定的目标。`find` 里的拉丁文是**站点用的新版拉丁**，书中中文是 1971 年版，**读经范围、对经措辞可能不同**；你的任务只是找到并如实转录，不判断配对。

## 怎样做

1. 用 PyMuPDF（`import fitz`，已安装）渲染页面图片到 `ocr-work/gaps/`。**定位**：页眉在页面最上方（约 6–11% 高度），横排、**从右向左读**（如「日三廿月二十」＝十二月二十三日），并有书页码。用 `dpi≈100` 渲染页面上部 12% 的小图，按日历顺序二分查找；可一次把十几页的页眉竖向拼成一张图再看。把 `anchors` 当起点。PDF 页码单调对应日历（将临期→圣诞期→常年期前几周→…；圣人专用部份按月日排）。
2. 找到后，**转录该条目涉及的所有页**（目标内容所在页，通常 1–4 页；若 `find` 列了多项如诵读一、诵读二、答唱、对经、集祷经，每项所在页都要）。规则同 `TASK-ocr-commons.md`（请先读它）：渲染 dpi=200，竖排每栏自右向左，每栏一行，块间空行，保留 ※＋☆ 等符号，看不清写〔?〕，不改字不补字；每页转完放大核对一次。
3. 结果**逐页追加**到 `ocr-out/gaps/<IDS 的第一个 id>.jsonl`（UTF-8，一页一行 JSON）。格式同 commons，另加两个字段：

```json
{"target": "xmas-jan10", "pdf_page": 380, "book_page": 330, "header": "一月十日", "kind": "text", "text": "…", "uncertain": 0, "note": ""}
```

   - `target`：该页对应的目标 id（一页对应多个目标时，每个目标各写一行，text 相同也可，或在 note 说明）。
4. 若某目标在书中**找不到**（页眉里没有该日/该周、或该日只有「經文見…」之类转引、或圣人不在书中）：写一行 `{"target": id, "pdf_page": null, "kind": "missing", "text": "", "note": "怎样查的、看了哪些页范围、为什么认为没有"}`。**不要为凑数而硬抄不相干的页**。
5. 若书中同一日有多年（甲乙丙）或多个选项，全部转录，在 `note` 里写清是哪一个。

## 其他要求

- 做完一页写一行，中途停下可接着做（先看目标 jsonl 已有哪些 target/页）。
- 不要修改仓库其他文件；图片放 `ocr-work/gaps/`。
- 结束时用中文简短报告：每个目标 → 找到的 PDF 页、书页码、是否发现与站点拉丁不符（如读经范围不同）、missing 的目标及原因、不确定字总数。
