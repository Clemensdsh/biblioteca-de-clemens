# 《每日颂祷》补时辰礼仪中文缺口：结果说明

写于 2026-11-22，接 `docs/LH_BOOK_GAP_FILL_PLAN.md`。本文记录补了什么、什么对不上不补，以及怎样重跑。工作到此收尾。

## 做法一句话

站点拉丁是第二版，万有真原与香港本两个在线来源缺中文的行，用《每日颂祷》（香港教区，1971 年版译本，竖排扫描本）补。Codex 看图转录，我逐条对照拉丁（作者与篇名、答唱出处、集祷经大意），**确为同一篇才配**；中文取自转录原文，只调整排版，繁体照印，简体视图由 OpenCC 转出并标「取自香港本」。

## 结果

- `public/data/liturgia-horarum/zh/ocr-commons.json`：202 行（含此前的圣母周六纪念禱詞 2 条）。
- 仍无中文的不同拉丁行：497 → 280（不含天主经引言、圣母周六纪念 `SPMVS*`，这两项另有处理或用户决定不补）。
- `vitest run features/liturgiaHorarum` 62 项通过。**页面渲染没在浏览器里看过**；转录未逐字校对，可能有形近字（祢/你、簡/揀 等）。

## 对不上，不补

| 项目 | 原因 |
|---|---|
| 圣高比 8/14、圣庇护 9/23 | 1971 年后才进礼历，书中无条目 |
| 另 26 个日期（如 2/7、4/2、4/4、4/5、5/10、5/13、5/21、5/22、7/5、7/24、8/2、8/9、8/12、8/16、8/23、9/5、9/9、10/11、11/15、11/25、12/9、12/10 等） | 书中无对应条目（后进礼历的圣人或非圣人日） |
| 12/12、10/9、10/16、7/20、8/25、1/27、9/28、5/29 | 同日书中是另一位圣人（如 12/12 拉丁瓜达卢佩、书中圣若安；8/25 拉丁加拉桑、书中圣路易），读经、答唱、集祷经都不同 |
| 将临期第三主日、圣家节、复活期第四/五主日、其他主日的赞主曲/谢主曲对经 | 书中每主日只印一条，不按甲乙丙年分；站点拉丁是乙年，措辞不同 |
| 1/7 诵读二 | 书中是另一篇讲道（讲主受洗），拉丁是金言伯多禄 Sermo 160 |
| 圣多明我 8/8 诵读一 | 书 欧 6:1–7:2，拉丁 5:14–7:2，范围明显更短 |
| 常年期第 7 周四诵读一 | 书缺拉丁 6:11 一节，范围不同（答唱已配） |
| 四旬期第四周四诵读一 | 书缺拉丁民 12:16 一节 |
| 访亲节 5/31 简短读经与短答唱 | 拉丁 友 13:18–19，书中 友 14:7b；短答唱领句不同 |
| 第 9 周 杜罗泰诵读二 | 书中第 9 周周四是另一篇，其余日期未找到 |
| 圣安博 12/7 赞美诗等各圣人/节日赞美诗 | 书转引通用部份，译文与拉丁不对应 |
| 圣母周六纪念 `SPMVS*`、天主经引言 | 另有专门组件／用户决定不补 |

不确定是新礼改版所致还是香港本的编排方式：对经按年分一项更像后者；圣人升格、新增圣人则确是 1971 年后的改动。

## 怎样重跑

```
node scripts/liturgia-horarum/build-ocr-commons.mjs            # 读 ocr-commons-pairs.json + ocr-gap-pairs.json，写 zh/ocr-commons.json
node scripts/liturgia-horarum/build-ocr-commons.mjs --check    # 只校验
npx vitest run features/liturgiaHorarum
```

`build-data.mjs` 会清空 `public/data/liturgia-horarum/`，重建数据后要重跑 `build-ocr-commons.mjs`、`build-wanyou-gap.mjs`、`build-bios.mjs`。

## 文件

| 作用 | 路径 |
|---|---|
| 配对（`auto-` 开头为脚本生成，其余手写） | `scripts/liturgia-horarum/ocr-gap-pairs.json` |
| 配对脚本与排版（reading / responsory / versicle / collect / antiphon / preces；`head`、`breaks`、`len` 选项） | `scripts/liturgia-horarum/build-ocr-commons.mjs` |
| Codex 转录 | `scripts/liturgia-horarum/codex/ocr-out/gaps/`（含 `saints/`、`pass3/`），任务说明 `TASK-gaps.md`，启动脚本 `run-ocr-gaps*.ps1`、`run-ocr-saints.ps1` |
| 目标清单与页码表 | `codex/gap-targets.json`、`codex/gap-saint-pages.json` |
| 导出仍缺的拉丁行 | `node scripts/liturgia-horarum/build-wanyou-gap.mjs --check --dump-gaps <file>` |
| 自由纪念半自动配对（临时脚本，按日期从转录切出诵读二/答唱/集祷经，**每个日期须人工对照拉丁后才放行；其 `REJECT` 列表即上表第 3 行**） | `artifacts/scratch/autopair.mjs`（重跑会覆盖 `auto-` 条目；依赖上一条导出的 `artifacts/scratch/gaps.json`） |

Codex 在 `codex/progress.md` 留了它自己的进度记录，可删。
